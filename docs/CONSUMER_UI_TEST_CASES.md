# 消费端界面验收：CityWalk、发现与页面切换

版本日期：2026-10-17。范围为消费端，后台管理界面不参与本轮换肤。

## 设计方向

沿用海迹现有的奶油纸色、薄荷绿、珊瑚色、墨绿轮廓与轻阴影。推荐页以图片、标题、正文摘要为主，手机双列，宽屏三列。点赞使用心形、收藏使用书签、推荐使用星形，选中同时改变形状填充与颜色；关注为胶囊按钮。发帖、帖子详情、我的内容列表和通用二级页共用控件语言。

设计参考：Material 的[组件与交互状态](https://m3.material.io/foundations/)、[颜色角色](https://m3.material.io/styles/color/the-color-system)及[动效](https://m3.material.io/styles/motion/overview/how-it-works)。采用清晰的信息层级与状态反馈，保留海迹的旅行风格。

## 操作前准备

- 本机：启动后端与前端，访问 `http://127.0.0.1:8788/`。正式环境使用已部署版本。
- 使用测试账号，避免对真实用户帖子进行测试性评论或发布。
- 建议分别以电脑宽度和 390×844 手机宽度测试。
- 地图需要已配置的高德 JS Key；地点详情依赖已有 OSM 查询服务。测试选点不需要调用高德步行规划。

## 功能用例

| 编号 | 操作 | 预期 |
| --- | --- | --- |
| CW-01 | 我的 CityWalk → 自己画一条 → 上海 → 任一步行圈 | 尚未选点时，地图已取景到可选地点，不能停留在城市级视野 |
| CW-02 | 等待附近地点返回，或搜索附近地点 | 新增候选触发重新取景；仍在同一个步行圈内 |
| CW-03 | 查看密集地点，放大／缩小 | 标注显示名称、已有摘要或类别；冲突标注收为小点，放大后重新展开；地点未被删除 |
| CW-04 | 鼠标悬停标注／键盘 Tab 聚焦／手机点击标注 | 出现地点卡；描述、地址、开放时间仅显示已有字段；资料缺失不编造 |
| CW-05 | 打开 OSM 地点卡后等待 | 通过已有 `/api/catalog/place` 按需读取详情；不会重新拉全城数据，不调用高德 POI 查询 |
| CW-06 | 点击“加入路线”，再选第二个地点 | 立即出现本地曲线、数量更新；只有点“规划步行路线”才请求实际步行路线 |
| CW-07 | 点已选地点 → 移出路线；切换起点 | 选择、连线与数量一致；原有距离核验结果失效 |
| CW-08 | 打开已保存 CityWalk 编辑，切换步行圈，返回 | 已保存地点能够恢复，坐标不重复转换，旧详情请求不覆盖新页面 |
| CW-09 | 地点服务暂不可用时查看详情 | 保留已有资料及选点能力，提示详细资料暂未连上；不把其他地点资料显示到当前点 |
| SO-01 | 打开发现 → 推荐／关注 → 搜索 | 图片卡包含城市、标题、已有正文摘要、作者和点赞图标；图片保留地图署名 |
| SO-02 | 打开测试帖子，依次点赞、收藏、推荐，再取消 | 图标状态和按钮可访问名称同时更新；失败时不伪装成功 |
| SO-03 | 关注／取消关注作者，返回关注流 | 状态与实际关注流一致；不能关注自己 |
| SO-04 | 发帖 → 带上历史行程／CityWalk | 方形路线图卡可选；编辑页、AI 草稿和操作按钮风格一致 |
| SO-05 | 关联路线后生成“轻快种草”草稿 | 标题使用实际城市、起终地点，正文按天分段；不虚构亲测、票价、距离或人流；采用前可以审阅 |
| SO-06 | 查看已经发布的帖子 | 原作者正文不被重新生成或覆盖，长文按段显示 |
| SO-07 | 快速切换帖子／返回，模拟慢网络 | 旧请求不覆盖新页面，地图和按钮没有错配 |
| NAV-01 | 旅行 → 发现 → 我的 → 二级页 → 返回 | 约 260ms 的轻过渡；返回方向正确，地图实例不复制 |
| NAV-02 | 滚动某个一级页后，再点当前标签 | 页面回到顶部，不重新播放切页动画 |
| NAV-03 | 开启系统减少动态效果 | 页面与互动动画关闭；功能照常可用 |
| NAV-04 | 连续快速切页 20 次 | 旧动画被取消，无残影、无法点击或位置错乱 |

## 自动测试与接口范围

执行 `npm run test:iteration`；定向测试：

```sh
node --test test/consumer-presentation.test.mjs test/walk-editor-preview.test.mjs test/map-presentation.test.mjs test/map-workspace.test.mjs test/page-navigation.test.mjs
```

覆盖坐标系、异步候选取景、缺失值、恶意 HTML、未知地点及跨源消息拦截、重复详情读取、100 次快速选点、陈旧路线响应、100 次动画替换、减少动态效果、文案事实约束。

现有接口参数不变。`GET /api/social/feed` 和帖子读取增加可选 `excerpt`（正文前 100 字）；旧客户端兼容。CityWalk 详情复用已有接口。数据库表结构不变。

本轮不自动补写没有来源的地点介绍，不改写用户已发布帖子。种草草稿通过受控的行程事实模板呈现，AI 选择语气和重点，仍需用户采用并发布。
