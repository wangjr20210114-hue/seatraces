## 功能边界

1. 兴趣证据经既有 profile / travelHabit 影响新问卷、候选景点评分和行程筛选。本轮修正了问卷选项只按标签插入顺序排列的问题；明确偏好优先，再按推断兴趣强度排列。已有问卷不擅自修改答案。
2. 顶层景点先按 personalInterest 再按原总分显示。父景点可承接少量最高子景点兴趣，避免子景点数量多就无限加分。最终安排仍先满足本次“想去”、开闭园、时间预算及地理约束，不保证所有高兴趣地点都能排进。
3. 发现滚动到底追加：先读当前冻结推荐池，耗尽后以已显示 ID 请求下一池。每5个位置保留一个探索位；去重、并发合并、过期恢复、失败保留卡片。每轮最多600张，避免页面无限增长。
4. 收藏/浏览复用图文卡片，显示作者、封面、城市、发布时间与收藏/最近浏览时间。浏览天数是不同日期的记录数，不是访问次数。
5. 顶层景点简介可悬浮或键盘聚焦展开。只为可见卡片按需请求；PostgreSQL 地点扩展表缓存，完整资料不进入问卷。仅名称/类别时保留基础介绍；模型只摘录已有证据，不编百科知识。
6. 问 AI 使用既有内部接口工作流与授权校验。RAG 已实际使用本机 BGE 512维向量，并修正知识文档和排序；无模型文件时接口明确返回 lexical，不能称为向量检索。

## 双塔诊断

详见 [训练诊断](TOWER_DIAGNOSIS_20261018.md)。完成7组 CPU 实验，最大参数24,577，为原来的4倍；全程82.69秒，峰值143 MiB。

模拟行为由余弦兴趣规则生成，所以余弦基线接近已知数据生成器。扩大模型后历史测试 NDCG@10 从0.8021提高到0.8080，基线0.8074，但验证集仍落后，差值置信区间包含0。实验模型未激活；保留原有上线质量门槛。该结果不能证明真实用户推荐质量提高，也不需要为此购买GPU。

本机成熟真实训练样本为0，不等于线上没有行为。训练器当前还按用户和内容两端的模拟标记区分数据范围，真实用户阅读模拟帖子不属于纯真实训练集。后续应单独评估这种混合数据，不能去掉标记冒充真实数据。

后续已实际完成 UniSRec 迁移，以及 BGE-base 中文、multilingual-E5-small、DIN、DCNv2 四类补充对照，详见 [旅行模型实验报告](TRAVEL_MODEL_COMPARISON_20261018.md)。这些离线结果仍未达到既有上线门槛。人工盲评只有一位评审的 20 道主要题，其中 11 道“两篇都合适”按用户原意保留，不能硬转为偏好胜负；不把这批已看过的诊断题当作独立上线验收集。

## 真实 DeepSeek 与 BGE 联调补记（北京时间 2026-10-18 18:33）

`scripts/verify-agent-grounded-live.mjs` 在本机隔离 PostgreSQL 中，经过实际 HTTP 会话接口、真实 BGE 和现有 DeepSeek 适配器完成 7 个场景。它不是生产环境或模拟器测试，也没有重新部署业务代码。

| 场景 | 核对内容 | 结果 |
|---|---|---|

| 平滑曲线是否等于道路 | 同上；避免把概览曲线说成实际步行道路 | 通过，引用 routes；1.637 秒 |
| 开放时间和票价是否猜测 | 同上；不生成无依据数字 | 通过，引用 place-descriptions / unknown；1.582 秒 |

前三项均确认模型返回的原文摘录有效并实际被采用，不是模型失败后由规则兜底冒充成功。每项重复提交相同 requestId 时返回一致结果、不重复调用模型；另一账号读取该会话返回 404。7 个场景合计业务接口调用尝试 0 次、动作表新增 0 条、地图调用 0 次、生产写入 0 次，临时账号和 schema 已清理。

成功运行共 8 次 DeepSeek 调用，耗时 11.210 秒，进程峰值 RSS 272 MiB、结束时 JS 堆 35 MiB。前一次运行因测试错误地把“分类＋回答”预期为一次调用而停止，修正断言后通过；前次已有 2 次正常供应商调用，因此本次两轮共 10 次，实际费用以供应商账单为准。失败与成功原始报告都保留，分别为 `validation/personalization/agent-grounded-1792319522098.json` 与 `agent-grounded-1792319581911.json`，不会将失败运行计入通过数。

外发数据仅为固定的虚构测试问题和公开的软件知识文档。已用 GitHub 匿名接口核对公开提交 `7b2cf31` 的 `server/agent/catalog.mjs` 与本机一致；新增载荷白名单拒绝账号、行程、坐标、记忆、对话历史及任意额外字段。2 项白名单边界测试通过。请求仍经过原有预算账本，脚本最多 8 次调用，不自动重试失败的供应商请求。

这一小批实测证明本次路径能跑通，不能证明任意自然语言均能准确分类；场外答复仍偏生硬，本轮未据此宣称对话体验已达到人工助手水平。

